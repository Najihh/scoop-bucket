# Najihh/scoop-bucket

Scoop bucket for **Weiß CODE** (`weiss`).

```powershell
scoop bucket add Najihh https://github.com/Najihh/scoop-bucket
scoop install weiss-code
```

`bucket/weiss-code.json` is generated by the release workflow in
[Najihh/Weiss](https://github.com/Najihh/Weiss) from `packaging/weiss-code.json.tmpl`.
Do not edit it by hand; the next release overwrites it.
